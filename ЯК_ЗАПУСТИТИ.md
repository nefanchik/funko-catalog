# Каталог 22FunkoShop

- Каталог у Telegram: https://t.me/funko22ua_bot?startapp
- Сайт: https://nefanchik.github.io/funko-catalog/
- Канал: @funko22ua · Бот: @funko22ua_bot · GitHub: https://github.com/nefanchik/funko-catalog

## Як це працює

Кожні ~15 хвилин GitHub сам читає канал @funko22ua і оновлює каталог:
- новий пост з «ПРИДБАТИ» → фігурка з'являється в каталозі;
- пост видалено (продано) → фігурка зникає;
- змінили ціну чи опис → змінюється і в каталозі.

Пишіть пости як зараз: назва **жирним**, серія *курсивом*, ціна «… грн», опис у цитаті,
кнопка-посилання «ПРИДБАТИ». Першим фото альбому ставте коробку — воно йде в сітку.

Посилання на конкретну фігурку: `https://t.me/funko22ua_bot?startapp=item_3028`
(3028 — номер поста з посилання `t.me/funko22ua/3028`).

## Якщо щось пішло не так

- **Оновити негайно:** https://github.com/nefanchik/funko-catalog/actions →
  «Синхронізація каталогу» → **Run workflow**.
- **Червоний хрестик у Actions з текстом «Сесія недійсна»** — ви завершили сеанс у
  Telegram (Налаштування → Пристрої). Запустіть `py login.py` у цій папці, увійдіть через QR
  і замініть секрет `TG_SESSION` у
  https://github.com/nefanchik/funko-catalog/settings/secrets/actions
- **Каталог перестав оновлюватись після довгої паузи** — GitHub вимикає розклад, якщо
  60 днів не було змін. Actions → Enable workflow / Run workflow.
- **«Отримано лише N позицій… зупиняюсь»** — захист від збою Telegram: якщо пришло менше
  половини постів, каталог не чіпається. Зазвичай наступний запуск проходить нормально.

## Файли

- `index.html` — сам каталог (вигляд, пошук, фільтри, назви категорій у `CATS`).
- `sync.py` — читає канал і оновлює `data.js` та `photos/` (запускає GitHub).
- `login.py` — одноразовий вхід у Telegram через QR, видає рядок `TG_SESSION`.
- `build.py` — запасний варіант: збирає каталог з HTML-експорту каналу.
- `.github/workflows/sync.yml` — розклад запуску на GitHub.

Рядок сесії `TG_SESSION` дає доступ до вашого акаунта Telegram — тримайте його тільки
в GitHub Secrets.
