# Каталог 22FunkoShop у Telegram

Папка `catalog` — готовий сайт-каталог, який відкривається прямо всередині Telegram як Mini App
(з кнопкою «Придбати», кнопкою «Назад» і кольорами теми Telegram).

Що в ній:
- `index.html` — сам каталог (пошук, категорії, сортування, фільтр за ціною, картка товару з фото).
- `data.js` — 401 фігурка, витягнута з експорту каналу.
- `photos/` — фото до них.
- `build.py` — оновлює `data.js` і `photos/` з нового експорту.

## 1. Викласти сайт в інтернет (безкоштовно, ~5 хв)

Telegram відкриває Mini App тільки за адресою `https://...`. Найпростіше:

**Netlify Drop**: відкрийте https://app.netlify.com/drop, увійдіть і перетягніть туди всю папку `catalog`.
Ви отримаєте адресу на зразок `https://funko22-catalog.netlify.app`.
(Альтернатива: GitHub Pages або Cloudflare Pages — теж безкоштовно.)

## 2. Підключити до Telegram

1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте ім'я, наприклад `funko22shop_bot`.
2. `/newapp` → оберіть цього бота → назва, опис, картинка 640×360 → вставте адресу з кроку 1 →
   коротке ім'я, наприклад `catalog`.
   Отримаєте посилання: `https://t.me/funko22shop_bot/catalog`
3. (Необов'язково) `/mybots` → бот → **Bot Settings → Menu Button** → та сама адреса,
   щоб каталог відкривався кнопкою в чаті з ботом.

## 3. Додати в канал

- Зробіть пост «🗂 Весь каталог — тут» з посиланням `https://t.me/funko22shop_bot/catalog` і закріпіть його.
- Посилання на конкретну фігурку: `https://t.me/funko22shop_bot/catalog?startapp=item_3028`
  (число — номер поста в експорті; його видно в адресі `#item-3028`, коли відкриваєте картку в браузері).

## 4. Кнопка «Пост у каналі» (за бажанням)

У `index.html` знайдіть `channel: ""` і впишіть username каналу без `@`,
тоді в картці кожної фігурки з'явиться посилання на її пост.

## Як оновити каталог

1. Експортуйте канал знову (Telegram Desktop → ⋮ → Експорт історії, формат HTML).
2. Запустіть:
   ```
   py build.py "C:\шлях\до\нового\ChatExport_..."
   ```
3. Знову перетягніть папку `catalog` у Netlify (або оновіть сайт там, де він розміщений).

Проданих фігурок експорт не позначає — якщо ви видаляєте пост після продажу,
після оновлення він сам зникне з каталогу.
