# Каталог 22FunkoShop у Telegram — з автооновленням

Як це працює: кожні ~15 хвилин GitHub сам читає ваш канал і оновлює каталог.
- новий пост з «ПРИДБАТИ» з'являється в каталозі;
- видалили пост (продано) — фігурка зникає з каталогу;
- змінили ціну чи опис у пості — зміниться і в каталозі.

Усе безкоштовно, комп'ютер може бути вимкнений.
Налаштування робиться один раз, приблизно 20 хвилин.

---

## Крок 1. Ключі Telegram

1. Відкрийте https://my.telegram.org → увійдіть своїм номером → **API development tools**.
2. Заповніть форму (App title: `funko catalog`, Platform: `Other`) → отримаєте **api_id** і **api_hash**.

## Крок 2. Вхід (на вашому комп'ютері, один раз)

Відкрийте термінал у папці `catalog` і запустіть:

```
py login.py
```

Введіть api_id, api_hash, номер телефону і код, який прийде в Telegram.
Скрипт покаже:
- список ваших каналів — запишіть `@username` або число для свого каналу;
- довгий рядок **TG_SESSION** — скопіюйте його повністю.

> ⚠️ Рядок сесії — це як пароль від акаунта. Не надсилайте його нікому і не зберігайте у файлах,
> тільки в GitHub Secrets (крок 4). Скасувати його можна будь-коли: Telegram → Налаштування →
> Пристрої → завершити сеанс. Для більшої безпеки можна увійти не основним акаунтом,
> а другим, який просто підписаний на канал.

## Крок 3. GitHub

1. Зареєструйтесь на https://github.com (безкоштовно).
2. Створіть **новий репозиторій**: https://github.com/new → назва, наприклад `funko-catalog` →
   **Public** (безкоштовний сайт тільки для публічних) → нічого не додавайте → **Create repository**.
3. У терміналі в папці `catalog` (підставте своє ім'я користувача):

   ```
   git remote add origin https://github.com/ВАШ_ЛОГІН/funko-catalog.git
   ```

   ```
   git push -u origin main
   ```

   Відкриється вікно входу в GitHub — увійдіть. Завантаження ~160 МБ фото триває кілька хвилин.

## Крок 4. Налаштування репозиторію

1. **Settings → Pages** → Source: **GitHub Actions**.
2. **Settings → Secrets and variables → Actions → New repository secret** — додайте чотири:

   | Name          | Value                               |
   |---------------|-------------------------------------|
   | `TG_API_ID`   | api_id з кроку 1                    |
   | `TG_API_HASH` | api_hash з кроку 1                  |
   | `TG_SESSION`  | рядок з кроку 2                     |
   | `TG_CHANNEL`  | `@username` каналу або його число   |

3. **Actions** → «Синхронізація каталогу» → **Run workflow**.
   Через 2–3 хвилини каталог буде за адресою `https://ВАШ_ЛОГІН.github.io/funko-catalog/`.

## Крок 5. Підключити до Telegram

1. [@BotFather](https://t.me/BotFather) → `/newbot` → ім'я, наприклад `funko22shop_bot`.
2. `/newapp` → цей бот → назва, опис, картинка 640×360 →
   адреса з кроку 4 → коротке ім'я, наприклад `catalog`.
   Посилання на каталог: `https://t.me/funko22shop_bot/catalog`
3. Закріпіть у каналі пост «🗂 Весь каталог» з цим посиланням.

Посилання на конкретну фігурку: `https://t.me/funko22shop_bot/catalog?startapp=item_3028`
(3028 — номер поста в каналі).

## Що варто знати

- **Формат постів.** У каталог потрапляють пости, у яких є кнопка-посилання «ПРИДБАТИ».
  Назва береться з **жирного** тексту, серія — з *курсиву*, ціна — з «… грн», опис — з цитати.
  Пишіть як зараз, і все спрацює.
- **Головне фото.** Для сітки береться перше фото альбому — ставте першим фото коробки.
- **Затримка.** GitHub запускає оновлення приблизно раз на 15 хв, буває до години.
  Щоб оновити негайно: Actions → Run workflow.
- **Захист.** Якщо Telegram раптом віддасть менше половини постів (збій), каталог не зміниться.
- **Сон.** Якщо в репозиторії 60 днів нічого не змінюється, GitHub призупиняє розклад —
  тоді просто натисніть Run workflow / Enable workflow у вкладці Actions.
- **Кнопка «Пост у каналі».** У `index.html` впишіть username каналу в `channel: ""`.
